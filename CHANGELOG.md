# Changelog

## 1.0.0

- Prompt-only production workflow across nine asset categories.
- Reusable base/category/asset profiles, production locks and compatibility checks.
- Complete German/English interface and persistent language selection.
- Main, negative, technical and combined prompt output; Markdown and JSON export.
- Original accessible SVG identity and consistent product version 1.0.0.
- Digest-pinned, non-root production image and read-only Docker Compose stack.
- Validated HTTPS/static hosting examples, operational guide and rollback procedures.
- Current user/maintainer documentation, with obsolete planning archives removed.
- Community guidance, contribution/support/security policies, safe issue forms
  and dependency license notices.
- Reproducible static release archives, checksums and runtime SBOM; gated
  multi-architecture GHCR releases and deployment of the exact released website.
- Production-browser verification of CSP, navigation, language persistence and
  real JSON backup/restore; interpreter-only validation avoids dynamic code execution.
- Preserved schema/export V2, persisted application identifier, all six storage
  keys, migration backup behavior and compatibility-only settings.

Earlier internal generation labels were not public releases. Historical
implementation details remain recoverable from Git history, not this public
product changelog. See [versioning rationale](docs/BRANDING.md).

Publication time and immutable artifacts are recorded in the corresponding
GitHub release; this changelog does not itself publish or approve a release.
