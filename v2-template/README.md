# V2 Target Scaffold

Diese Ordnerstruktur ist eine **Architekturvorlage**, kein fertig installiertes Projekt. Codex soll in Migrationsphase 1 das echte Vite-React-TypeScript-Projekt im Repository-Root einrichten, kompatible aktuelle Pakete installieren und `package-lock.json` erzeugen.

Die `latest`-Einträge in dieser Vorlage dienen nur als Zielabhängigkeitsliste und sollen nicht blind als Release-Lock verwendet werden.
