# PixelForge Studio 3.0 — historische Release-Abnahme

## Status

Die frühere V3-Produktstufe mit Animation Studio wurde nach ihrer Abnahme aus
dem produktiven Arbeitsbaum entfernt. Dieses Dokument bleibt als stabiler
Verweis für ältere Changelog- und Archivlinks bestehen, beschreibt aber keine
aktuelle Produktfunktion.

Das aktuelle Produkt ist ausschließlich das **PixelForge Prompt Studio V2**.
Seine Schema-, Storage-, Migrations- und Exportverträge blieben beim Rückbau
unverändert. Die damaligen vollständigen Umsetzungsunterlagen und
Abnahmenachweise liegen unter
[`erledigt/pixelforge-studio-v3/`](erledigt/pixelforge-studio-v3/).
