# PixelForge Prompt Studio 1.0.0

The first public release of the local-first prompt studio for consistent
pixel-art production. Create prompts, not images: nine category-aware workflows,
reusable production profiles and locks, and main/negative/technical/combined
Markdown output. German and English interfaces are selectable in Settings.

## Run it

Use the versioned AMD64/ARM64 GHCR image with Docker Compose, or deploy the
checksum-verified static archive to an HTTPS web server. Exact image references
are in `container-image.txt`; pin the digest for production. The archive contains
site files at its root, not inside a `dist` directory.

[Self-hosting, HTTPS and rollback](https://github.com/kleiveist/PixelForgeStudio/blob/v1.0.0/docs/SELF-HOSTING.md)
documents source builds, published images, static hosting and reverse proxies.
Check each download against `SHA256SUMS`; runtime notices, a CycloneDX SBOM and
build provenance accompany this release. The image runs as a non-root user with
a read-only filesystem and no server-side database.

## Data and compatibility

Profiles, drafts and settings live only in your browser's localStorage. There is
no account, telemetry, cloud sync, AI API integration or backend. Export a JSON
workspace from Settings before clearing browser data, changing host/port/scheme
or upgrading. Server backups do not back up your browser. Import validates data
before applying it and reports conflicts.

Product version **1.0.0** is independent from schema/export **2**. All six
`pixelforge:v2:*` keys, the persisted `PixelForge Prompt Studio` identifier and
legacy prompt migration remain compatible. The retired animation-project
workspace, renderer and engine exports are not part of this product.

## Browser support and limitations

Release gates cover current Playwright Chromium and Firefox on Linux, including
routes, keyboard navigation, reduced motion, narrow layouts, persistent language
selection and JSON download/import through the real production container. Safari
and mobile devices are not release-certified. Browser storage may be restricted
or evicted; keep JSON backups. Private/incognito sessions are not durable storage.
There is no cross-device synchronization or server-side authentication.

Custom names, notes and imported prose are preserved verbatim, not automatically
translated. Prompt-output language is separate from the interface language.
HTTPS is recommended; the built-in server is intended to sit behind your TLS
reverse proxy. Supply your own hostname and certificate configuration.

## Community and support

[GitHub Issues](https://github.com/kleiveist/PixelForgeStudio/issues) and pull
requests are the supported public channels. Read the community and contribution
guides before participating; use only sanitized examples. Report vulnerabilities
through the repository's private vulnerability-reporting form, not a public issue.
The latest stable 1.x release receives best-effort maintenance without a response
or hosting SLA; see [Security](https://github.com/kleiveist/PixelForgeStudio/blob/v1.0.0/SECURITY.md)
and [Support](https://github.com/kleiveist/PixelForgeStudio/blob/v1.0.0/SUPPORT.md).
